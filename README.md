# Desktop-Application-ImGui-Template-Visual-Studio
Template To ImGui Based
## Download
Download File "Desktop Application ImGui.zip" And "ImGuiBuild"(in releases).
Create a folder in “C:\Users\user\Documents\Visual Studio 18”(by default) named “My Exported Templates” and copy my “Desktop Application ImGui.zip” file into it.
Go to the “C:\Users\user\source\repos” folder (by default, all your projects are located there) and unzip and copy the “ImGuiBuild.zip” file. End.
